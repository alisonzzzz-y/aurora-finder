# 历史缺测布局与时区选择验收

## 修改

- 历史回看始终渲染两张图的容器、标题、数值占位和坐标网格。选中缺测时段时，在图中显示“没有数据”，不卸载图表，不将缺测填成零。
- 采样状态行、数值行和图表读数行预留固定空间，滑动经过缺测时段不会改变区域高度。
- 时区默认显示设备时区及 UTC、英国、爱尔兰、中欧、冰岛、北美东部/太平洋、中国、日本、澳大利亚东部、新西兰。设备或已选时区不在常用列表时自动保留。
- 其他时区通过城市名、IANA 时区名或本地化时区名称搜索，每次最多显示 8 个匹配。支持 Enter 选首项、Esc 取消；常用地区同时显示当前 UTC/GMT 偏移，日期换算继续使用 IANA 地区规则处理夏令时。

## 验证

- 前端 lint、38 项测试、TypeScript 和生产构建通过。既存 MapLibre 大包提示仍在。
- 在独立 Chromium 中使用明确的本地测试快照：20:00 与 21:00 有数据，中间三个 15 分钟时段无记录。其余 API 通过测试代理读取生产公开数据，没有修改生产 CORS。
- 在 390px 和 1280px 下，使用方向键连续经过有记录/无记录/有记录：两张 SVG 始终存在，原 SVG 节点没有卸载，整个结果区域高度逐次相等。
- 鼠标按住时间轴连续移动 13 次，结果区域高度始终为 479.1953125px，图表数量始终为 2。
- 搜索 Tokyo 后 Enter 正确选中 Asia/Tokyo；无匹配查询显示明确空状态；Esc 关闭搜索；搜索“日本”返回 Asia/Tokyo；常用下拉在测试设备上为 11 项。
- 手机搜索面板无整页横向溢出，已检查缺测图表和搜索面板截图。

## 边界

缺测回归使用测试数据，未写入生产历史记录。时区选择作用于全球 Kp 趋势及其读数，历史回看仍明确使用 UTC。移动端验证为 Chromium 窗口尺寸检查，不等同于真机验收。
