## 产品功能边界

- 综合观测规则在 OutlookService 中始终返回 NOT_VALIDATED / INSUFFICIENT_DATA。这是主动保留的不确定性，不是数据 API 无法连接。没有独立验证数据前不能改成已验证，也不能声称预测个人观测概率。
- “较佳观测地点”只显示等待数据条件满足的说明，目前没有候选地点排序或推荐实现。
- 三晚黑暗时段已计算，但 WeatherService 仅保留当地今晚中午至次日中午的云量。第二、三晚没有云量是当前接口范围限制。若要支持三晚天气，需要同步扩展时间范围、来源标签、页面与 AI 工具测试。
- 历史图显示社区报告数量，不能支持“过去十年最佳观测城市”的排名或城市出现频率结论。
- 固定热门地点面板、地点比较、提醒尚未完成。附近地点比较是后续扩展，需要可靠的位置、交通时间、开放条件与观测数据。
