# 综合观测规则验证结论

核对日期：2026-10-01。状态：**尚未通过，不启用整晚低、中、高等级或个人看到极光的概率**。

## 已核对的证据

- NOAA 短时极光模型只给未来约 30–90 分钟的活动信号；云量来源给当地今晚及近期逐小时预报；太阳位置计算提供三个暮光边界。它们的时间范围不总是重叠。即使重叠一个云量点，也不足以推出整晚观测等级。
- 本地 Aurorasaurus cleaned 数据质量审计确认“明确看到”和“晴空但明确未看到”可作为候选标签，但报告是自愿提交，事件和地区分布不均；没有报告不是未看到。
- 历史 OVATION 档案与报告的探索性匹配出现缺档、磁纬覆盖不足、半球与数值单位未核实。2025 候选窗口中，匹配成功的正负标签模型值分布重叠，且这些窗口此前已被查看，不能再作为独立留出集。
- 当前没有已验证的云量、黑暗程度、模型信号与地面可见结果之间的组合阈值，也没有可用于校准个人概率的系统性观测样本。

详细数据、来源、脚本与局限见 [观测数据审计](aurora-rule-validation-data.md)。

## 现行确定性规则

| 输入情况 | 页面和接口结果 | 解释 |
| --- | --- | --- |
| 来源当前可用，且短时模型与云量时间至少部分重叠 | `NOT_VALIDATED` + `INSUFFICIENT_DATA` + `RULES_NOT_VALIDATED` | 时间重叠不等于整晚观测规则通过验证。原始活动、云量和黑暗时间仍单独展示。 |
| 一个或多个来源失效、缺测或不重叠 | 同上；各来源和覆盖状态独立报告 | 缺测不转换成晴空、低概率或低等级。 |
| 高纬度极昼或黑暗时间计算失败 | 同上；太阳边界状态独立报告 | 不把没有足够黑暗时段误报成已经验证的观测等级。 |

当前服务按所选地点当地日期生成三晚窗口，综合结果始终保持上述保守状态。运行记录写入规则版本 `abstain-unvalidated-v1` 与实际来源状态，便于以后检查，但不会因为建立数据库而自动改变规则。

## 解除阻断所需工作

1. 固定数据来源版本、历史模型单位和南北半球语义，补齐档案缺口与空间/时间匹配误差。
2. 在看结果前固定事件级训练、验证与独立测试切分，处理候选重复和自愿报告偏差；对每个地区、事件强度和季节公布有效样本量与缺测比例。
3. 预先定义整晚可用时间窗口、云量与天黑边界的处理方法、质量门槛和评价指标。短时模型不能直接外推到三晚。
4. 用独立留出数据检验候选等级的区分能力、误报和漏报。若要显示概率，还需额外做校准检验。证据不足的地区和夜晚必须继续弃权。

这些条件尚未完成，因此本次开发的可交付结果是明确的验证结论、保守规则、来源证据和可追查的运行记录，而非未经证实的观测等级。
