## 本次补齐的工程工作

- GitHub CI 加入真实 MySQL 8.4 测试和桌面/手机浏览器回归，不再只检查编译。
- 浏览器测试覆盖选择后 Enter、中文输入法 Enter、AI 地点记忆和重试、浮窗拖动缩放关闭、历史缺档和时区键盘搜索。固定来源数据，不消耗 OpenAI 额度，不依赖外部服务稳定性。
- AI 单实例全局限制默认每 10 分钟 24 次、同时 2 次；保留每客户端 8 次限制。失败也消耗请求预算，但释放并发名额。重启会清空内存计数，不声称有持久化费用封顶或分布式限流。
- 运行记录使用最多 3 个连接的连接池；修复父记录读取时嵌套申请连接的问题。单连接测试覆盖完整子记录读取。
- 持久化启用时，启动检查写入合成记录和工具证据、读回上一实例的检查记录、验证合成过期记录及子记录被清理。日志只记录随机检查 ID，不记录密钥或用户聊天。
- `APP_RUN_RECORD_RETENTION_DAYS` 现在明确绑定保留期。公开历史仍独立保留 7 天。
- 增加隔离 MySQL 备份恢复演练脚本。它创建自己的容器，不连接生产库，退出时清理。
- 更新前端依赖锁定版本，修复本次 `npm audit` 报告的高危开发依赖问题。
- 修复地点详情和附近比较两个相邻组件使用同一 React key 的问题。
- 浏览器日志、截图和报告加入忽略规则，避免进入公开仓库。

## 可复现验收

在仓库根目录，安装前端依赖后运行：

```sh
bash scripts/check_local.sh
cd frontend
npx playwright install chromium
npm run test:e2e
```
