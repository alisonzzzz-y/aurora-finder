# Nearby city index / 附近城市目录

Source / 来源: GeoNames, https://download.geonames.org/export/dump/cities15000.zip
License / 许可: CC BY 4.0, https://creativecommons.org/licenses/by/4.0/
Retrieved / 获取日期: 2026-10-14

Derived from cities15000. Only ID, name, country code, coordinates and timezone are retained. Covers mainly cities above 15,000 residents and capitals, not every settlement. No viewing quality or access claims are inferred.

由 cities15000 提取编号、名称、国家代码、坐标和时区，主要覆盖人口超过15,000的城市及首府，不覆盖全部村镇，不推断观测质量或地点通行条件。
